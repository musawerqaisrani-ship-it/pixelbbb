# Urdu Fonts Directory

Place your TrueType Font (`.ttf`) files in this directory to load local Urdu typography:

1. `JameelNooriNastaliq.ttf` - Jameel Noori Nastaliq
2. `JameelNooriKasheeda.ttf` - Jameel Noori Kasheeda
3. `AlviNastaleeq.ttf` - Alvi Nastaleeq
4. `MehrNastaliq.ttf` - Mehr Nastaliq
5. `NotoNastaliqUrdu.ttf` - Noto Nastaliq Urdu
6. `NotoSansArabic.ttf` - Noto Sans Arabic
7. `Gulzar.ttf` - Gulzar
8. `Amiri.ttf` - Amiri
9. `Lateef.ttf` - Lateef
10. `ArefRuqaa.ttf` - Aref Ruqaa

The web app in `style.css` is configured with relative `@font-face` rules for these files, alongside Google Fonts web CDN fallbacks for web browsers.
